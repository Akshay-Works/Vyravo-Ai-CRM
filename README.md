# Vyravo AI — CRM

Standalone CRM for [vyravo.ai](https://vyravo-ai.vercel.app) — leads, pipeline, clients, projects, meetings, proposals, invoices & analytics.

- Full lead management with pipeline stages
- Receives leads automatically from the Discovery Call Automation app (shared Neon Postgres database)
- Dashboard analytics, meetings, tasks, proposals & invoices

Part of the Vyravo AI app family:
- Main site: https://vyravo-ai.vercel.app
- Email Automation: https://vyravo-ai-email-automation-yf54.vercel.app
- Discovery Call Automation: https://vyravo-ai-discovery-call.vercel.app

## Development
```bash
npm install
npm run dev
```
